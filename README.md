# Velo International School Website

A modern and responsive website designed for **Velo International School**. The website provides information about the school, academics, admissions, campus life, latest updates, and contact details.

## 📌 About the Project

This project is a frontend school website with a clean, professional, and user-friendly design. It is built to provide a smooth browsing experience on **desktop, tablet, and mobile devices**.

The website includes responsive navigation, interactive elements, animations, school information, academic programs, admission sections, and a professional footer.

## ✨ Features

* 🏫 Modern school website design
* 📱 Fully responsive layout
* 🧭 Responsive navigation menu
* 📚 Academic programs section
* 🎓 Admissions section
* 🏫 Campus Life section
* 📰 Latest news and school updates
* 📊 School statistics section
* 📞 Contact information
* 🔗 Social media links
* ✨ Smooth scroll animations
* 🖱️ Interactive hover effects
* 📱 Mobile hamburger menu
* 🎨 Clean and professional UI

## 🛠️ Technologies Used

* **HTML5** - Website structure
* **Tailwind CSS** - Styling and responsive design
* **JavaScript** - Website interactions and animations
* **Font Awesome** - Icons
* **Google Fonts** - Typography

## 📂 Website Pages

The website includes the following main sections:

* **Home** - School introduction and highlights
* **About Us** - Information about the school
* **Academics** - Academic programs and learning pathways
* **Admissions** - Admission information and application options
* **Campus Life** - Campus and student activities
* **Contact** - Contact and school information
* **Latest Updates** - News, events, and achievements

## 🎨 Design

The website uses a professional education-focused design with **dark blue, gold, and light blue** colors. It also uses modern cards, rounded corners, shadows, images, hover effects, and smooth animations.

## 📱 Responsive Design

The website is optimized for different screen sizes:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

The navigation automatically changes to a mobile-friendly hamburger menu on smaller screens.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Run the project using **Live Server**.
5. Open the website in your browser.
